# CozyBite

**A cozy bilingual recipe discovery website built with React and TypeScript.**

CozyBite is a personal web development project designed to make discovering recipes simple, enjoyable, and visually inviting. The application focuses on a warm, user-friendly interface, bilingual accessibility, and interactive recipe browsing.

**Project Status:** In Development

## Links

- **Live Demo:** https://cozy-bites-beta.vercel.app
- **GitHub Repository:** https://github.com/SySbunny21/CozyBites

## Features

- **Bilingual Support:** Switch between English and Chinese.
- **Light & Dark Themes:** Customize the appearance of the website.
- **Recipe Categories:** Explore recipes through organized categories.
- **Interactive Navigation:** Browse recipes using responsive interface components.
- **Recipe Discovery:** Explore recipes through search and recommendation features under ongoing development.

## 🚀 Getting Started

To run the project locally:

1. Clone the repository:

   `git clone https://github.com/SySbunny21/CozyBites.git`

2. Navigate to the frontend directory:

   `cd CozyBites/frontend`

3. Install dependencies:

   `npm install`

4. Start the development server:

   `npm start`

*Note: The start command may vary depending on the project's current configuration.*
